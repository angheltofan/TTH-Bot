# TTH Bot

TTH Bot is an AI-powered conversational educational assistant developed for Tales & Tech Hub.

The project explores natural voice interaction between children and an AI assistant through a simple and engaging interface.

## Features

- Real-time voice interaction
- Push-to-talk mode
- Conversational AI
- Educational conversations
- Interactive riddles and games
- Cross-platform support
- AI API integration
- Real-time communication
- Simple child-friendly interface

## Tech Stack

- Flutter
- Dart
- AI APIs
- WebSockets
- Real-time audio
- Cross-platform application development

## Purpose

The goal of TTH Bot is to make AI interaction accessible and engaging in an educational environment.

Instead of being only a chatbot interface, the application focuses on voice-first interaction and educational activities.

## What I Learned

- real-time application architecture
- voice interaction workflows
- AI API integration
- conversational UX
- asynchronous communication
- handling real-time application state
